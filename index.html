Gerencie suas aventuras

O Portal RPG é uma plataforma planejada para auxiliar mestres e jogadores na criação, organização e gerenciamento de campanhas de RPG.

Nesta primeira etapa, a aplicação apresenta a estrutura necessária para o gerenciamento de campanhas.

Ferramentas planejadas

O Portal RPG poderá receber novas funcionalidades durante as próximas etapas de desenvolvimento.

  • Criador de fichas de personagens
  • Rolagem de dados
  • Gerenciamento de personagens
  • Biblioteca de sistemas de RPG
  • Consulta de regras através de API
  • Criação de homebrews
  • Criador de habilidades
  • Criador de magias
  • Criador de itens
  • Gerador de monstros
  • Gerador de personagens para one-shots
  • Criador de pistas
  • Codificadores e decodificadores
  • Criador de enigmas
  • Ferramentas para criação de mundos
  • Gerador de masmorras
  • Mapas de campanha
  • Gerenciamento de sessões
  • Combate virtual
  • Tabletop virtual
